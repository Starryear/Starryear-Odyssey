Starryear-Odyssey-Photo-Diptych
V5 清洁史诗版更新说明（26 AUG 2026）

1. 视觉方向更新
- 史诗感改由尺度、围困、路径、重复、材质重量与远近关系建立。
- 明确禁止烟尘罩层、污迹、喷溅、做旧划痕、假胶片损伤、无来源碎屑与过量颗粒。
- 默认明暗检查收紧为近黑少于 25%、死黑少于 8%；失败时只重做下联并抬升源色阴影。
- 画面优先少而准、结构清楚、关键元素可追溯，保留宽广可读的中间调。

2. 网站更新
- 新增完整 GitHub Pages 视觉网站与 21 张图像画廊。
- 首屏及中段均提供明显的 Skill ZIP 与 TXT 完整口令下载入口。
- 新增留言窗口，填写内容后可直接带入仓库 GitHub Issue 提交页。

3. 下载文件更新
- `Starryear-Odyssey-Skill.zip` 已替换为 V5 清洁史诗版。
- 新增 `odyssey-photo-diptych-final-v5.zip` 和 `Starryear-Odyssey-完整口令-v5-清洁史诗版.txt`。

以下保留原有完整更新记录：

1. 作品数量补齐
- 从原总览的 9 张补齐为 16 张完整作品。
- 新增蛛网、钟楼与反射空间、秋林人物、松鼠、历史建筑、火焰等照片的《奥德赛》双联转译。
- 补入 THE LONG RETURN，避免总览漏图。

2. 全部统一为上下双联结构
- 上半部分直接使用原始照片，保持像素内容不变。
- 下半部分为从照片证据与《奥德赛》情节生成的原创抽象画。
- 交界过渡只发生在下联内部，不覆盖、不调色、不重绘上联照片。
- 编号、日期、英文情节名统一由可靠排版工具添加。

3. 新增统一卡片与 9:16 总览
- 16 张作品统一为相同黑底、作品框、标题位置、字号和编号系统。
- 新增 2160×3840 的 9:16 竖向总览，16 张全部入画，最后一张居中收尾。
- Skill ZIP 内同步收录 16 张统一示例卡片和总览图。

4. 龟溪作品重做
- 删除容易显得俗气的具象龟壳与壳纹装饰。
- 将两只龟转译为两个克制的种子形坐标，以水流、岩面、漂浮节点构成 LOTUS SHORE。
- Skill 新增“反俗套检查”：禁止放大龟壳、毛皮、爪子、眼睛等动物局部成为装饰中心。

5. 原图色彩对应加强
- 下联主要颜色必须来自原图主色、阴影、中间调、高光与强调色。
- 不再给所有照片统一套用蓝橙、黑金或橙色烛光滤镜。
- 新增自然光、烛火光、阴天/临界光三种曝光模式。

6. 烛火与死黑控制升级
- 烛火成为照亮石材、木材、烟雾、水面、织物和金属的局部叙事光源，而不是漂浮在黑底上的橙色点。
- 新增色调检测脚本：默认近黑面积不超过 30%，死黑面积不超过 12%。
- 新增作品与龟溪重制版均通过色调阈值检查。

7. 《奥德赛》元素更明确但不堆砌
- 加入可按照片证据调用的巨型木马、独眼巨人眼环、卡律布狄斯漩涡、斯库拉六重压力、塞壬、织机、弓与冥界等标志性母题。
- 母题必须融合进原图已有的尺度、孔洞、方向、重复、围困或路径关系，禁止作为贴纸或廉价奇幻角色出现。
- 本批新增对应包括 PENELOPE'S LOOM、THE WAITING HOUSE、ATHENA KEEPS WATCH、HALL OF SUITORS 与 DESCENT TO THE UNDERWORLD。

8. 电影视觉研究边界更清楚
- 吸收公开资料中可迁移的物理质感、史诗尺度、自然光与局部火光原则。
- 不复制电影镜头、海报、演员造型，也不直接模仿在世导演的个人风格。

9. Skill 工具链完善
- 调色板提取：extract_palette.py
- 色调与死黑检测：analyze_tone.py
- 原图像素保持、自然交界与文字排版：compose_diptych.py
- 最终版已逐张验证上联原图像素一致性。
